# 数据、权限与原生进程说明

## 权限和数据

- Manifest 的 `permissions` 为 `[]`。插件不调用宿主的数据库、查询、凭据、剪贴板、文件选择器或网络代理 API。
- DBX 启动一个随包提供的 Go 原生 Sidecar，通过标准输入/输出上的 JSONL RPC 通信。原生代码具有当前用户的操作系统权限；空 Manifest 权限不代表操作系统沙箱。
- 运行时只在 `DBX_PLUGIN_DATA_DIR` 保存自己的随机玩家标识、昵称、游戏积分、界面/声音偏好和已应用结算标记。独立预览可以通过 `--data` 指定隔离目录；未配置时使用系统用户配置目录下的 `DouDB`。
- 目录权限为 `0700`，保存文件为 `0600`，通过临时文件加重命名更新。没有遥测、分析 SDK、远程登录、云端存档或后台上传。
- DB 豆仅为游戏积分，没有充值、购买、兑换或现金价值。当前积分可以为负数。

## 网络行为

- 正常单机对局不打开 TCP 服务。大厅的房间刷新/扫描会使用临时 UDP socket 向广播地址和回环地址的 `19528` 端口发送 `DOUDB_DISCOVER_V1`，接收房间名、地址、容量和人数。
- 用户创建局域网房间时，房主监听 `0.0.0.0` 的一个系统分配 TCP 端口，并尝试监听 UDP `19528` 进行发现；房间关闭或进程退出后监听结束。固定 UDP 端口不可用时仍可手动加入。
- 手动加入只接受私有、回环或链路本地 IP 地址及端口，使用有超时限制的 TCP 连接；不连接公共互联网游戏服务。
- 加入房间时向房主发送本插件的玩家资料（随机玩家标识、昵称、游戏积分、界面/声音偏好及本地结算标记）；对局中发送会话标识和牌局动作。房主仅返回各客户端自己的手牌与公开信息。连接凭据用于恢复座位，保存在进程内存中，不写入公开日志。局域网协议未加密，当前仅用于可信局域网；不提供公网匹配、房间密码或房主迁移。
- `--preview` 开发模式额外启动仅监听 `127.0.0.1` 的 HTTP 页面/API 服务；发布后的 DBX Sidecar 默认不会启动该预览服务。

## 执行与素材

- 运行时不执行 shell、外部命令、安装器、子进程、更新下载器或其他可执行文件。
- 全部 UI、牌面和音频逻辑来自包内资源；音乐和音效使用 Web Audio 本地合成，不读取外部音频或 CDN。
- 源码使用 Apache-2.0。未修改的官方 DBX Go SDK 位于 `backend/sdk/`，包含上游 LICENSE 和 NOTICE；原创牌面 SVG 与 Web Audio 乐曲随项目授权。

## 验证范围

已通过 Go race/规则/存储测试、双进程集成测试与不透明 iframe 下的两套皮肤及 56 组布局验证。macOS ARM64 开发包已由作者安装到 DBX 并打开大厅，宿主内发现的布局问题已在 v0.1.4 修复；该更新在模拟宿主 iframe 中验证。跨电脑实机 LAN 与更新后完整原生宿主回归仍待验证。界面目前仅提供简体中文。
