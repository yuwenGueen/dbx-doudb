## DouDB v0.1.4

首个 DBX Store 候选版本，适用于 **macOS Apple Silicon（darwin-arm64）**，DBX >= 0.6.0。界面为简体中文。

- 三人经典 / 四人双副牌斗地主，电脑补位、提示、选牌、托管与结算。
- 单机对战和可信局域网房间；支持 UDP 发现及手动 IP:端口加入。
- 经典棋牌 / 数据库两套主题，主题和牌面分开维护；竖排 JOKER 与红黑小丑区分大小王。
- 炸弹、王炸、飞机与结算动效，原创本地合成背景音乐和音效。
- v0.1.4 修复 DBX 面板内高度适配，常见桌面尺寸大厅完整显示，手牌与出牌按钮保持可见，窄窗口保留局部滚动。

### 安装与审核状态

本 Release 为未签名审核候选包。开发测试可在 DBX 插件中心允许未签名开发包后安装 `.dbxp`；正式商店包由 DBX Store 维护者审核后统一签名。发布候选 Release 不表示已通过商店审核。

### 已知边界

DB 豆是本地积分，可以为负数，没有充值、兑换或真钱交易。当前没有公网匹配、房主迁移或房间加密；跨电脑 LAN 和更新后完整 DBX 原生回归仍待验证。其他平台暂未作为支持目标发布。

### Validation

Go race tests, 3/4-player rule and storage tests, two-process LAN integration smoke, and 56 responsive layout combinations in an opaque sandbox iframe. Native macOS ARM64 package; Chinese UI. See [data and network disclosure](https://github.com/yuwenGueen/dbx-doudb/blob/v0.1.4/docs/security.md).
